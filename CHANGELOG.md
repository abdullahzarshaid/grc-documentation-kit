# Changelog

All notable changes to the GRC Documentation Kit.

## 1.1.0 (2026-10-26)

- Added a full HIPAA set: HIPAA in plain words, a privacy policy, a security policy, the required security risk analysis procedure, the breach notification procedure, a business associate agreement, the Security Rule mapped to the kit, and a safeguard matrix register covering every standard and implementation specification of 45 CFR 164.308, 164.310, 164.312, 164.314 and 164.316, with the required or addressable flag and the implementing kit document for each.
- Added a HIPAA readiness playbook (PB-11).
- The kit now covers six frameworks: ISO/IEC 27001, ISO/IEC 27701, SOC 2, GDPR, HIPAA and AI governance.
- Animated the hero and the document-hierarchy diagrams and the three playbook timelines as SVGs that render on GitHub.
- Added a social preview image and Open Graph and Twitter card metadata for link previews.
- Enriched repository topics for discoverability.

## 1.0.0 (2026-10-26)

- First release: original policies, procedures, plans, templates, checklists, playbooks and Excel registers for ISO/IEC 27001:2022, ISO/IEC 27701, SOC 2, GDPR and AI governance, with a crosswalk between them.
- Build pipeline from Markdown masters to Word and Excel, a searchable site, a landing page, and a verifier that enforces original content, resolved cross-references and macro-free, link-free workbooks.

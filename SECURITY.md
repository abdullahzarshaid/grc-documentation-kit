# Security and privacy notice

This repository contains templates, not software that runs on your systems. The generated Word and Excel files contain no macros, no external links and no hidden sheets; `tools/verify.py` checks that on every change and the continuous check runs it on every push.

If you find a problem that affects users of the kit (for example a formula that hides an error, a register that could leak data when shared, or a document that misstates a legal obligation), open an issue with a fictional example. Do not attach a filled register, evidence from a real assessment, or anything that names a real organisation or person.

Never commit completed registers, evidence, screenshots or client material to a fork of this repository. The templates are designed so that a filled copy lives in your own controlled storage, not in a public repository.
